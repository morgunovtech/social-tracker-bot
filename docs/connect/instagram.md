# 📸 Instagram

🇬🇧 [In English](instagram.en.md) · [Все подключения](../SETUP.md#остальные-подключения)

Бот раз в день читает число подписчиков через официальный API Instagram и раз в полчаса сверяет имя, описание, ссылку и число публикаций профиля. Это самое долгое подключение: токен выдаёт кабинет Meta для разработчиков.

## Сколько займёт и что понадобится

Около 15 минут. Аккаунт Instagram должен быть профессиональным — «Автор» или «Бизнес»: в приложении «Настройки» → «Тип аккаунта», бесплатно. Понадобится аккаунт Facebook для входа на developers.facebook.com; Meta попросит создать бизнес-портфолио — тоже бесплатно, проверка для своего аккаунта не нужна.

## Шаги

1. Откройте [developers.facebook.com](https://developers.facebook.com/) → «My Apps» → «Create App» и пройдите мастер: сценарий, связанный с Instagram (в кабинете он сейчас называется «Manage messaging & content on Instagram»), тип — «Business».
2. В приложении: «Use cases» → «Customize» у сценария Instagram → «API setup with Unified login» — именно его, не «with Instagram login»: бот читает данные через Graph API Facebook. В шаге «1. Configure your app» создайте конфигурацию.
3. «App roles» → «Roles» → назначьте своему аккаунту Instagram роль **Instagram Tester** и примите приглашение в Instagram: «Настройки» → «Website permissions» → «Tester invitations».
4. Вернитесь в «Customize» → шаг «2. Generate access tokens» → «Add account», если аккаунта там нет, и нажмите **Generate token** напротив него. Скопируйте токен.
5. В боте: 🔌 Подключения → «➕ Instagram» → пришлите @username, затем «📸 Instagram» → «🔑 Прислать токен» и пришлите токен. Бот проверит, что токен выдан именно этому аккаунту, и сразу удалит сообщение.

Интерфейс Meta меняется часто (подписи выше сверены с кабинетом 27.11.2026): если подпись не совпадает, ищите ближайшую по смыслу.

**Сколько живёт токен.** Срок зависит от того, как Meta его выдала: токены входа через Instagram, по документации Meta, живут 60 дней. Когда Meta перестанет принимать токен, бот один раз скажет «токен отклонён» и будет напоминать в отчёте — нажмите «Generate token» снова и пришлите новый через «🔑 Прислать токен». Чтобы не ждать отказа, обновляйте токен заранее, раз в полтора-два месяца.

## Что бот читает и куда это уходит

Раз в день — число подписчиков, раз в полчаса — @username, имя, описание, ссылку в профиле и число публикаций (Graph API Meta, с вашим токеном). Только публичные данные вашего аккаунта. Токен хранится в базе бота, в бэкап и в лог не попадает. Если Meta отклонит токен, бот скажет об этом один раз и будет напоминать в отчёте, пока не придёт новый.

## Как отключить и удалить

🔌 Подключения → «✏️ Instagram» → пришлите «-». Приложение удалите на developers.facebook.com: приложение → «App settings» → «Advanced» → «Delete app».
