# ▶️ YouTube

🇬🇧 [In English](youtube.en.md) · [Все подключения](../../README.ru.md#настройка)

Бот раз в день читает число подписчиков вашего канала и раз в полчаса сверяет его название, описание, аватарку и число видео — пропавшие видео и чужая ссылка в описании бывают первыми признаками угона.

## Сколько займёт и что понадобится

Около 5 минут, аккаунт Google и ID канала. Ключ YouTube бесплатный: дневного лимита Google хватает с большим запасом.

## Шаги

1. **ID канала.** [studio.youtube.com](https://studio.youtube.com) → «Настройки» → «Канал» → «Расширенные настройки» → «Идентификатор канала»: 24 знака, начинается с `UC`. Подойдёт и ссылка вида `youtube.com/channel/UC…`.
2. **Проект в Google Cloud.** Откройте [console.cloud.google.com](https://console.cloud.google.com/), вверху — выбор проекта → «New project», любое имя → «Create».
3. **Включить API.** В поиске наверху наберите «YouTube Data API v3», откройте его и нажмите «Enable».
4. **Ключ.** «APIs & Services» → «Credentials» → «Create credentials» → «API key». Скопируйте ключ.
5. **Ограничить ключ** (советуем): в окне ключа «Edit API key» → «API restrictions» → «Restrict key» → отметьте только «YouTube Data API v3» → «Save». Тогда утёкший ключ ни на что другое не сгодится.
6. **В боте:** 🔌 Подключения → «➕ YouTube» → пришлите ID канала, потом ключ. Бот проверит пару живым запросом к вашему каналу, сразу удалит сообщение с ключом и начнёт собирать.

## Что бот читает и куда это уходит

Раз в день — статистику вашего канала с вашим ключом (`googleapis.com`), раз в полчаса — название, описание, аватарку и число видео. Ключ хранится в базе бота, в бэкап и в лог не попадает.

## Как отключить и удалить

🔌 Подключения → «✏️ YouTube» → пришлите «-». Ключ удалите в Google Cloud: «APIs & Services» → «Credentials» → ключ → «Delete»; проект можно удалить целиком.
