# Установка

🇬🇧 [In English](SETUP.en.md) · [Зачем это](WHY.md) · [Все возможности](FEATURES.md) · [README](../README.ru.md)

Это мой личный инструмент, открытый как есть: бесплатно, с открытым кодом (MIT), я пользуюсь им каждый день. Это не сервис с поддержкой — установку и подключения придётся пройти самому; для этого есть пошаговая инструкция и skill для Claude, который проведёт по шагам в браузере. Если окажется, что это нужно многим, сделаю облачную версию, где ничего не нужно ставить и настраивать.

Ниже — путь по кликам: бот в Telegram, хостинг Railway, первая сеть. Минут десять. Свой сервер вместо Railway — в конце.

## Сколько стоит

Сам бот бесплатный. Он должен где-то работать круглосуточно:

- **Railway.** Первые 30 дней — пробный период: $5 на счёте, карта не нужна. Чтобы пробный период был полным (с выходом в интернет без ограничений), входите в Railway через GitHub. Дальше — план Hobby: **$5 в месяц**, в них входит $5 использования, этого боту хватает. Для Hobby нужна обычная (не предоплаченная) карта, которой можно платить за рубежом.
- Если после пробного периода не перейти на Hobby, бесплатного плана ($1 в месяц) круглосуточному боту может не хватить: он **молча остановится**, а том с базой пробного аккаунта Railway удаляет через 30 дней после окончания пробного периода.
- **Свой сервер** — бесплатно: любой компьютер или VPS с Docker (последний раздел).
- **Проверка комментариев** (по желанию) — платный ключ Claude по вашему счёту: около $0,01 за комментарий.

Цены Railway сверены с [docs.railway.com](https://docs.railway.com/reference/pricing/plans) 27.11.2026 — перед установкой проверьте, не изменились ли они.

## Шаг 1. Бот в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram и нажмите «Запустить».
2. Отправьте `/newbot`.
3. Пришлите имя бота — как он будет называться в чате, например «Мой трекер».
4. Пришлите username — латиницей, на `bot` в конце, например `my_tracker_bot`. Если занято, BotFather попросит другой.
5. BotFather пришлёт токен: цифры, двоеточие и около 35 букв, например `123456789:AAH…`. Скопируйте его. Это ключ от бота — никому его не показывайте.

## Шаг 2. Railway

1. Нажмите кнопку [![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/social-tracker-bot?referralCode=7hTMqE). В ссылке — мой реферальный код Railway: Railway делится со мной частью оплаты аккаунта, созданного по ней; для вас цена та же. Тот же шаблон без кода: <https://railway.com/deploy/social-tracker-bot>.
2. Войдите в Railway — лучше через GitHub (см. «Сколько стоит»).
3. Нажмите **Deploy Now**, затем **Configure** — до этого кнопка Deploy серая. Вставьте токен в поле `BOT_TOKEN` (это единственное поле) и нажмите **Save Config**.
4. Нажмите **Deploy** и подождите пару минут, пока у сервиса не появится статус **Online**.
5. Проверить, что бот запустился: в проекте откройте сервис → **Deployments** → **View Logs** — там должна быть строка `Bot ready`.

## Шаг 3. Первый /start

Откройте своего бота (`t.me/<username бота>`) и нажмите «Запустить». Бот ответит «✅ Теперь этот бот твой» — первый, кто нажал `/start`, становится владельцем, остальным бот не отвечает. Поэтому сделайте это сразу после установки.

Язык бот берёт из вашего Telegram: русский остаётся русским (как и узбекский, казахский, киргизский, таджикский и белорусский — тогда и пояс ставится по стране), любой другой становится английским. Поменять — ⚙️ Настройки → «🗣 Язык / Language».

## Шаг 4. Первая сеть

Вторым сообщением бот откроет 🔌 Подключения. Проще всего начать с Telegram-канала: сделайте бота администратором канала — бот сам напишет и предложит подключить этот канал одной кнопкой. Пошагово: [connect/telegram.md](connect/telegram.md). Потом выберите часовой пояс (главная → «🌍 Выбрать часовой пояс»), чтобы отчёт приходил в ваше утро. Как только первая сеть подключится, бот сам предложит сторожа.

## Если что-то пошло не так

- **Бот отвечает «Это личный бот».** Кто-то нажал `/start` раньше вас. Узнайте свой id у [@userinfobot](https://t.me/userinfobot), затем на Railway: сервис → **Variables** → **New Variable**, имя `ADMIN_CHAT_ID`, значение — ваш id. Railway перезапустит бота, и он будет отвечать только вам. Язык при этом бот из Telegram не возьмёт — выберите его в ⚙️ Настройках.
- **Бот молчит.** Railway → сервис → **Deployments** → **View Logs**. Нет строки `Bot ready`, а есть `Telegram refused BOT_TOKEN` или `BOT_TOKEN is not a bot token` — токен скопирован не целиком или отозван: возьмите его снова у @BotFather и поменяйте в **Variables**.
- **Бот перестал отвечать через месяц.** Скорее всего, закончился пробный период Railway: откройте Railway → **Usage** и перейдите на Hobby. Чтобы узнать о такой остановке сразу, подключите ⏱ Сторожа.
- **Обновления.** Когда выходит новая версия, Railway предлагает обновить проект прямо в нём — согласитесь, и после перезапуска бот напишет «🔄 Бот обновился».
- **Как удалить.** Удалите проект на Railway (настройки проекта → удалить; база удалится вместе с ним) и бота у @BotFather командой `/deletebot`. Ключи, которые вы создавали для подключений, удалите там, где создавали, — это сказано на каждой странице `connect/`.

## Помощь Claude

Если не хочется проходить шаги одному, это сделает Claude: skill «install-social-tracker» ведёт по установке прямо в браузере (Claude in Chrome или встроенный браузер Cowork) — говорит, что нажать, и проверяет, что получилось. Входы в аккаунты, оплату и пароли он оставляет вам.

**Claude Code** — две команды в сессии, затем попросите «установи Social Tracker»:

```text
/plugin marketplace add morgunovtech/social-tracker-bot
/plugin install social-tracker-setup@social-tracker-bot
```

**claude.ai и Cowork** — скачайте `install-social-tracker.zip` со страницы [последнего релиза](https://github.com/morgunovtech/social-tracker-bot/releases/latest), затем Customize → Skills → «+» → «Create skill» → «Upload a skill» и выберите архив. Навыкам нужно включённое выполнение кода: Settings → Capabilities → «Code execution and file creation». Путь в меню — по справке Claude на 27.11.2026: если он изменился, ищите загрузку навыка в разделе Skills.

## Свой сервер

На компьютере или VPS с Docker бот ставится одной командой — она спросит токен, заберёт образ и запустит бота:

```bash
curl -fsSL https://raw.githubusercontent.com/morgunovtech/social-tracker-bot/main/scripts/install.sh | sh
```

Или вручную через `docker compose` — см. [README](../README.ru.md#установка). Дальше всё то же: `/start`, первая сеть.
