# 🔎 Reputation report — only for site owners

Guide for people: https://github.com/morgunovtech/social-tracker-bot/blob/main/docs/connect/reputation.en.md (Russian: reputation.md).

Ask first whether the user has a site of their own in Google Search Console, Yandex Webmaster or Cloudflare. No site — skip this step entirely.

In the bot: «🔌 Подключения» → «🔎 Репутация» → «🏷 Брендовые слова» (the user's name and product names, comma-separated), then «🔑» per source the user has. Follow the guide page for each key (a Google service account added to Search Console; a Yandex OAuth token; a Cloudflare token with Zone Read and Analytics Read). Every key is read-only; the user creates it under their own sign-in. Stop and describe the screen when a console's labels don't match the guide.
